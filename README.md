# Информационная система "Приемная комиссия БППК"

Информационная система для управления процессом приема абитуриентов в Белгородский правоохранительный педагогический колледж.

## Технологии

- **Backend**: ASP.NET Core 8.0 MVC
- **ORM**: Entity Framework Core 8.0
- **База данных**: PostgreSQL 16
- **Аутентификация**: ASP.NET Core Identity
- **Frontend**: Razor Views, Bootstrap 5
- **Контейнеризация**: Docker & Docker Compose

## Функциональность

### Для абитуриентов
- Регистрация и вход в систему
- Просмотр образовательных программ
- Подача заявок на обучение
- Отслеживание статуса заявок
- Управление своими заявками (черновики)

### Для сотрудников приемной комиссии
- Просмотр всех поданных заявок
- Фильтрация заявок по статусу
- Рассмотрение заявок
- Изменение статуса заявок
- Добавление комментариев к заявкам

### Для администраторов
- Все возможности сотрудников
- Просмотр статистики по заявкам
- Анализ загруженности программ
- Управление системой

## Роли пользователей

1. **Applicant** (Абитуриент) - может подавать и отслеживать свои заявки
2. **Staff** (Сотрудник) - может просматривать и рассматривать заявки
3. **Admin** (Администратор) - полный доступ к системе

## Установка и запуск

### Предварительные требования

- .NET SDK 8.0 или выше
- Docker и Docker Compose (для PostgreSQL)
- Git

### Шаги установки

1. **Клонируйте репозиторий**
```bash
git clone <repository-url>
cd Practice
```

2. **Запустите PostgreSQL через Docker**
```bash
docker-compose up -d
```

3. **Примените миграции базы данных**
```bash
dotnet ef database update
```

4. **Запустите приложение**
```bash
dotnet run
```

5. **Откройте браузер**
```
https://localhost:5001
или
http://localhost:5000
```

## Конфигурация базы данных

По умолчанию строка подключения в `appsettings.json`:

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Host=localhost;Database=admission_bppk;Username=postgres;Password=postgres"
  }
}
```

Вы можете изменить её под свои настройки PostgreSQL.

## Миграции базы данных

### Создание новой миграции
```bash
dotnet ef migrations add <MigrationName>
```

### Применение миграций
```bash
dotnet ef database update
```

### Откат миграции
```bash
dotnet ef database update <PreviousMigrationName>
```

## Статусы заявок

- **Draft** (Черновик) - заявка создана, но не подана
- **Submitted** (Подана) - заявка подана на рассмотрение
- **UnderReview** (На рассмотрении) - заявка рассматривается
- **Accepted** (Принята) - заявка одобрена
- **Rejected** (Отклонена) - заявка отклонена
- **Withdrawn** (Отозвана) - заявка отозвана абитуриентом

### Требования к паролям

- Минимум 6 символов
- Должен содержать минимум одну цифру
- Должен содержать минимум одну строчную букву

```bash
dotnet dev-certs https --trust
```
